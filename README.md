# 🎯 Guess The Number

A simple and interactive Number Guessing Game built with **HTML, CSS, and Vanilla JavaScript**.

The computer randomly selects a number between **1 and 100**, and the player tries to guess it using hints.

## ✨ Features

* 🎲 Random number generation
* 🔢 Guess numbers between 1–100
* ⬆️ "Too High" hint
* ⬇️ "Too Low" hint
* 🎉 Correct answer message
* 🔢 Attempt counter
* 🔄 New Game functionality
* ⚠️ Input validation
* ⌨️ Enter key support
* 📱 Responsive design
* 🎨 Clean and modern UI
* ⚡ No backend or database required

## 🛠️ Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Game logic and interactions

1. Clone the repository:

```bash
git clone https://github.com/your-username/guess-the-number-game.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

That's it! No installation or dependencies are required.

## 🎮 How to Play

1. The game generates a random number from **1 to 100**.
2. Enter your guess in the input field.
3. Click **Guess** or press **Enter**.
4. Follow the hint:

   * **Too Low** → Try a higher number.
   * **Too High** → Try a lower number.
5. Continue until you find the correct number.
6. Click **New Game** to start again.
